# B76

BODC Platform Models

A collection of terms used to describe designs or versions of platforms.

NVS Vocabulary URL: http://vocab.nerc.ac.uk/collection/B76/current/

Search interface: [https://vocab.nerc.ac.uk/search_nvs/B76/](https://vocab.nerc.ac.uk/search_nvs/B76/)

## Request for new terms and ways to contribute
- Requests for a new B76 can be submitted as [regular issues](https://github.com/nvs-vocabs/B76/issues) in this repository or emailed to vocab.services-at-bodc.ac.uk.

- Reporting errors or suggestions for improving content can be also be submitted as above.
